# スクリーンショット撮影ガイド / Screenshot Guide

README・Qiita・Note で参照している画像の一覧と撮り方です。
**ファイル名のとおりに `docs/screenshots/` へ保存**してください（参照パスが一致します）。

- 推奨ブラウザ: Chrome / Edge（PWA・カメラ対応）
- 推奨ウィンドウ幅: **1280px 前後**（ヘッダーが1行に収まります）。モバイル系は DevTools のデバイスエミュレーション（375px）
- テーマは「ライト」か「ダーク」で統一すると記事が見やすいです（ヘッダー右の◐アイコン）
- 撮影は OS の範囲指定スクショ（Windows: `Win + Shift + S`）か、ブラウザ拡張のフルページ撮影が便利です
- 顔や周囲が写り込むカメラ画像は、**印刷したマーカーやスマホに表示したマーカー**を被写体にすると安全です

> マーカーは本アプリの「生成」タブで作って印刷／別画面表示すると、すぐ認識テストできます。
